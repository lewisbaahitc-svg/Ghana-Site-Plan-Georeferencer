2. Coordinate conversion & CAD output

The traced coordinates can be displayed/exported in another system. For UTM, latitude/longitude is required as the conversion source. For Ghana grids, the datum and grid definition must match the plan.

Choose an output system and complete a boundary.
3. Coordinate consistency check

Before placing the points on the satellite map, this check compares the entered control coordinates under the two main Ghana grid interpretations. It does not change your survey coordinates.

Add at least 3 control points to run the check.
Important: If your plan has Eastings around 1,300,000 and Northings around 419,000, Ghana National Grid / Accra Datum (EPSG:2136) is the first system to test. Ghana Metre Grid (EPSG:25000) gives a very different geographic position for those same numbers.
3. Online satellite / map verification — no Google API key required

This version uses public web map tiles for visual verification. Satellite imagery is supplied by Esri World Imagery; the normal map uses OpenStreetMap. No Google Maps API key is required.

Manual coordinate plotting on the satellite map

After georeferencing and tracing your boundary, copy the generated coordinates and paste them here. You can paste one point or several points. Use one point per line, in Easting, Northing order, or choose latitude/longitude below. The program will plot exactly those coordinates on the satellite map without recalculating the site-plan image.

Plot box accepts clean coordinate pairs only: Easting, Northing (one pair per line), or latitude, longitude for WGS84. Do not paste distance, bearing or area.
Paste your coordinates above, then click “Plot coordinates on satellite”.
Click “Load map” while connected to the internet. No API key is needed. You can also manually paste coordinates above and plot them.
Imagery: Esri World Imagery and its credited data providers. Map data: © OpenStreetMap contributors. The red boundary comes from your georeferencing controls and is not altered by the background imagery.
4. Load the site-plan photograph
Load a JPG, PNG or WebP photograph to begin.
5. Georeference using control points

Enter a known Easting/Northing from the plan, click Add control, then click the matching grid intersection on the image. Use at least 4 well-spaced points, preferably near the corners. Four or more points enable perspective correction.

No control points yet.
6. Trace the parcel boundary

After calibration, click parcel corners in order. The output boundary is highlighted in red.

Blue = control points • Red = parcel boundary. When placing a point, a precision crosshair follows your finger/mouse and a 4× magnifier helps you hit the exact location.
6. Quality control
Add control points to calculate calibration quality.
Four or more well-distributed control points are recommended. The perspective calculation uses normalized coordinates for numerical stability when Easting/Northing values are large. Residuals are a calibration check, not a substitute for authoritative survey control.
